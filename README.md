# 간식약탈단 — SNACK RAIDERS Edition

사용자가 제공한 확정 규칙:
- 시비가 걸리면 본인 선에서 해결
- 여미새·남미새 행동 금지
- 길드 퀘스트 주 2~3회

페이지 완성도를 위해 추가한 BASIC 04~08은 제안 규칙입니다. 실제 운영진 확인 후 수정 가능합니다.
현재 BGM과 가입 문의 링크는 제공되지 않아 미포함입니다.


## BGM 업데이트
- YENA — 캐치 캐치 로컬 BGM 포함
- 음악과 함께 입장 / 조용히 입장
- 기본 볼륨 8%, 부드러운 페이드인
- 재생/정지, 진행률, 볼륨 플레이어
- 입장 시 CATCH! 팝업 연출
- 음악 재생 중 과자 패키지/라벨 미세 비트 애니메이션
